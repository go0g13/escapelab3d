Privacy Policy — EscapeLab3D Uploader

Last updated: November 4, 2026

EscapeLab3D Uploader is a private tool used only by the owner of the Escape Lab 3D YouTube channel to upload and schedule the channel's own videos through the YouTube Data API.

What data it uses

With the owner's permission it uses the YouTube scopes needed to upload videos and to read the channel's name, so it can confirm it is uploading to the right channel. It does not access any other user's data.

How data is stored

The access token is stored only on the owner's own computer. No data is sold, shared with third parties, or used for advertising.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.

This tool uses YouTube API Services. See the YouTube Terms of Service and the Google Privacy Policy.
